How to use

Press Enter to move through the Italian bind-off loop. The blue text shows the action you are currently doing.

Loop order: Knit Off → Purl On → Purl Off → Knit On

Use Right/Down arrows to go forward, and Left/Up arrows to go backward.

Knits: Knit Off / Purl On
Purls: Purl Off / Knit On
Do the highlighted motion, then press Enter to mark it done.
Press ← if you need to go back.
Enter = done / next. Left arrow = back. Clear = all black.
